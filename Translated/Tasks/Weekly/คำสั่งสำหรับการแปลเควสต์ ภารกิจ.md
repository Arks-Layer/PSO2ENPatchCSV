# 📋 คำแนะนำสำหรับการแปลไฟล์เควสต์และภารกิจ (Quest/Task Translation Guideline)

## 1. 🎯 เป้าหมาย (Goal)
แปลข้อความระบบที่เกี่ยวข้องกับ "เควสต์ (Task / Quest)" เช่น เควสต์รายวัน (Daily Tasks) หรือ เควสต์ฉุกเฉิน (Emergency Quests) ให้มีความสั้น กระชับ เข้าใจเงื่อนไขได้ทันที และใช้ภาษาที่เกมเมอร์คุ้นเคย ห้ามแปลผิดไปจากต้นฉบับ

## 2. ⚙️ โครงสร้างไฟล์และรูปแบบ (Formatting)
* **รักษา ID ด้านหน้าไว้:** เช่น `Title#0`, `Summary#0`, `text0101#0` ห้ามลบหรือแก้ไขเด็ดขาด
* **ตัวแปรระบบ (ถ้ามี):** หากเจอโค้ดตัวแปร เช่น `%d`, `{0}`, `%s` หรือโค้ดไอคอน ห้ามแปลและห้ามลบ ให้วางไว้ในตำแหน่งที่ถูกต้องตามหลักภาษาไทย
* **ข้อกำหนดทางเทคนิค:**
    * **Encoding:** ต้องบันทึกไฟล์เป็น **UTF-8** เท่านั้น
    * **Newline:** ต้องมี **บรรทัดเปล่าปิดท้ายไฟล์เพียง 1 บรรทัด** เท่านั้น ห้ามขาดหรือเกิน หากมีอยู่แล้วไม่ต้องใส่เพิ่ม ต้องมีแค่ 1 บรรทัดเท่านั้น

## 3. 🗣️ แนวทางการแปลตามโครงสร้างเนื้อหา (Translation Rules)
ไฟล์กลุ่มนี้มักจะมีโครงสร้าง 3 บรรทัดหลัก ให้แปลตามแนวทางดังนี้:

* **Title (ชื่อเควสต์):** แปลให้เป็นชื่อหัวข้อที่กระชับ ใช้คำที่ดูเป็นชื่อภารกิจหรือชื่อบทความ
    * *ต้นฉบับ:* `Title#0,"Enemy Subjugation"`
    * *คำแปล:* `Title#0,"ปราบศัตรู"`
    * *ต้นฉบับ:* `Title#0,"Completing Daily Tasks I"`
    * *คำแปล:* `Title#0,"สำเร็จเควสต์รายวัน I"`

* **การใช้เครื่องหมายพิเศษ (Brackets):**
    * หากมีชื่อเฉพาะหรือข้อความที่อยู่ในเครื่องหมายคำพูด (เช่น `"Ordinal Tower"`) ให้เปลี่ยนมาใช้เครื่องหมาย **【 】** แทน เพื่อความสวยงามและอ่านง่าย
    * *ตัวอย่าง:* `"Ordinal Tower"` → `【Ordinal Tower】`

* **Summary (คำอธิบายเงื่อนไข):** อธิบายว่าผู้เล่นต้องทำอะไรแบบตรงไปตรงมา ไม่ต้องใส่สรรพนาม (ฉัน/ผม/คุณ)
    * *ต้นฉบับ:* `Summary#0,"Defeat any Enemies."`
    * *คำแปล:* `Summary#0,"กำจัดศัตรูประเภทใดก็ได้"`
    * *ต้นฉบับ:* `Summary#0,"Complete the specified number of Daily Tasks within the time period."`
    * *คำแปล:* `Summary#0,"สำเร็จเควสต์รายวันตามจำนวนที่กำหนดภายในระยะเวลา"`

* **text (เป้าหมายที่ต้องทำ):** ให้ขึ้นต้นด้วย **"คำกริยา"** เสมอ เพื่อให้เป็นประโยคคำสั่งที่ชัดเจนและเข้าใจง่ายสำหรับเกมเมอร์ เช่น กำจัด, ผ่าน, เคลียร์, เก็บ, รวบรวม
    * (หากเจอคำว่า Complete หรือ Clear ในช่องนี้ ให้ใช้คำว่า **"ผ่าน"** แทนคำว่า สำเร็จ)
    * (หากเจอคำว่า Obtain หรือ Get ในช่องนี้ ให้ใช้คำว่า **"เก็บ"** หรือ **"รวบรวม"** แทนคำว่า รับ)
    * *ต้นฉบับ:* `text0101#0,"Defeat Enemies"`
    * *คำแปล:* `text0101#0,"กำจัดศัตรู"`
    * *ต้นฉบับ:* `text0101#0,"Obtain Genesis Points from your GP Tree"`
    * *คำแปล:* `text0101#0,"เก็บ Genesis Points จาก GP Tree ของคุณ"`
    * *ต้นฉบับ:* `text0101#0,"Complete Daily Tasks"`
    * *คำแปล:* `text0101#0,"ผ่านเควสต์รายวัน"`

## 4. 🎮 คำศัพท์เฉพาะที่พบบ่อยในหมวดนี้ (Terminology)
* **Task:** เควสต์ (ไม่ต้องใช้คำว่า ภารกิจ)
* **Daily Tasks:** เควสต์รายวัน
* **Emergency Quests:** Emergency Quests (ทับศัพท์)
* **Defeat:** กำจัด
* **Clear:** เคลียร์ / สำเร็จ
* **Complete:** สำเร็จ
